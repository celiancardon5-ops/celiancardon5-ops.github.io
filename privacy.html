Privacy Policy

Last updated: 2026.

Clips Shorts is a personal application used only by its owner. It uses the YouTube API Services to upload videos to the owner's own YouTube channel.

Data we access

The app accesses only the owner's YouTube account, with the owner's permission, to upload videos. It does not collect data about any other person.

Data storage and sharing

Authorization tokens are stored locally on the owner's computer. No data is sold, shared with or transferred to third parties.

YouTube and Google

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at security.google.com/settings/security/permissions.
